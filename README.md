# Portfolio Szymona

Portfolio przygotowane w HTML, CSS i JavaScript w ramach Warsztatu Programisty.

## Zawartość

- `index.html` — przedstawienie się, poznawane technologie i przycisk z ciekawostką.
- `about.html` — studia, zainteresowania i cele nauki.
- `projects.html` — dwie karty projektów pozostawione do uzupełnienia.
- `styles.css` — wspólne style oraz układ dostosowany do szerokości ekranu.
- `script.js` — obsługa przycisku „Pokaż ciekawostkę”.

Aby obejrzeć stronę lokalnie, otwórz `index.html` w przeglądarce.
